# TAYTA — El que sabe, enseña

Prototipo de una comunidad donde adultos mayores comparten sus conocimientos mediante clases virtuales y presenciales.

## Ejecutar

Abre esta carpeta en Visual Studio Code y ejecuta index.html con Live Server, o sube los archivos a un hosting estático. No requiere instalar dependencias ni compilar.

## Funciones del prototipo

- Catálogo con búsqueda, filtros y favoritos.
- Perfiles locales de práctica.
- Publicar, editar y eliminar clases propias.
- Modalidad virtual, presencial o ambas.
- Foto opcional desde el dispositivo.
- Diseño adaptable a computadoras y celulares.

## Alcance actual

Los datos se guardan en IndexedDB del navegador: no se sincronizan entre equipos. Los perfiles no tienen autenticación real y los pagos no están conectados. No introducir información privada.

## Próximo enfoque a validar

Facilitar que los adultos mayores compartan su experiencia, por sí mismos o con una persona de apoyo autorizada. Este enfoque está en análisis; no todas sus pantallas están implementadas.

## Archivos

HTML: pantallas. css/: estilos. js/: lógica del prototipo. assets/: fotografías ilustrativas. LEEME.txt: instrucciones detalladas de la versión.
